# 🕰️ מיל — יישומון להצגת זמני היום העבריים

**מיל** (באנגלית: *Mil*) הוא יישומון רספונסיבי אינטראקטיבי המציג את השעה הנוכחית לצד "שעה זמנית" (Halachic Hour) בהתבסס על זמני הזריחה והשקיעה במקום בו נמצא המשתמש.

## 📛 על השם

**מיל** הוא מידת המרחק ההלכתית — המרחק שאדם מהלך ברגל ב-18 דקות. השם נושא שתי משמעויות שנפגשות ביישומון:

- **זמן** — 18 הדקות של המיל, שהן גם מניין ח״י, ומשמשות בין השאר לשיעור צאת הכוכבים
- **מרחק** — המילה שאולה מלטינית, *miliarium*: אבן המיל הרומית שסימנה את המרחק בדרכים

האייקון מצייר בדיוק את המפגש הזה — אבן מיל רומית שעליה חקוק **XVIII** (18), לצד השמש הנמוכה שמטילה את הצל שהוא עצמו מד-הזמן.

## ✨ תכונות עיקריות

- 🕒 **שעה נוכחית** לפי אזור הזמן של הדפדפן
- ☀️ **זמני זריחה ושקיעה** בהתאם למיקום הגיאוגרפי
- 📐 **שעה זמנית (Halachic Hour)** מחושבת על פי זמני היום או הלילה
- ⏳ **משך שעה זמנית** (כמה דקות אורכת כל "שעה")
- 🎨 **רקע משתנה ויזואלית לפי מצב יום/לילה**, עם אפשרות לקבע ערכה בהירה או כהה ידנית
- ⭐ **צאת הכוכבים** — 18 דקות אחרי השקיעה, ולצדו שיטת רבנו תם (72 דקות זמניות)
- ⏭️ **הזמן ההלכתי הבא** עם ספירה לאחור, והדגשת הכרטיס הרלוונטי
- 🕌 **כיוון תפילה** לאבן השתייה שבהר הבית, עם מצפן חי
- 🧭 **תאריך עברי בגימטריה + תאריך לועזי מלא**
- 📱 **רספונסיבי מלא** — מותאם לניידים ולדסקטופ
- 🧠 **מעבר חלק בין מצבים** עם אייקונים קטנים ותצוגה ברורה

## 🛠️ טכנולוגיות בשימוש

- HTML, CSS, JavaScript בלבד
- `Intl.DateTimeFormat` עבור תאריך עברי ולועזי
- חישוב זמן זמני לפי יחס זריחה–שקיעה
- [SunCalc](https://github.com/mourner/suncalc) 1.9.0 (רישיון MIT) — מוגש מתוך `vendor/suncalc.js`
  ולא מ-CDN חיצוני, כדי שלא תהיה תלות בקוד צד שלישי שיכול להתחלף תחת אותה כתובת
- Service Worker לתמיכה במצב offline

## 🔒 פרטיות ואבטחה

- **מיקום** — המיקום מתקבל מהדפדפן (בהסכמת המשתמש) או, אם אין הרשאה, מזיהוי לפי כתובת IP
  דרך [ipapi.co](https://ipapi.co). המיקום משמש לחישוב זמני היום בדפדפן בלבד ואינו נשמר בשרת כלשהו.
- **שם היישוב** — מתקבל בעזרת reverse geocoding מ-[Nominatim (OpenStreetMap)](https://nominatim.openstreetmap.org)
  ובנפילה ל-[BigDataCloud](https://www.bigdatacloud.com). הקואורדינטות הנשלחות לשירותים אלה
  מעוגלות לשלוש ספרות אחרי הנקודה (כ-100 מטר), והתוצאה נשמרת במטמון מקומי לשבוע
  כדי לצמצם את מספר הפניות לשירותים החיצוניים.
- **Content-Security-Policy** — מוגדרת פעמיים בכוונה: כ-HTTP header ב-`firebase.json` (המנגנון
  המועדף, שחל גם על נכסים שאינם HTML), וכ-`<meta>` ב-`index.html` כגיבוי לפריסה סטטית ללא שליטה
  ב-headers, כגון GitHub Pages. שתי ההגדרות חייבות להישאר מסונכרנות.
  אין `unsafe-inline`: כל ה-JS וה-CSS בקבצים חיצוניים, ו-`connect-src` מוגבל לשלושת השירותים לעיל.
- **תוכן חיצוני** — שמות יישובים מגיעים ממקור הניתן לעריכה ציבורית ולכן מוזרקים לדף
  כטקסט בלבד (`textContent`), לעולם לא כ-HTML.
- **גופנים** — גופני מערכת בלבד, ללא טעינה מ-Google Fonts, כדי שלא ידלפו כתובות IP של משתמשים.

## 🎨 יצירת האייקונים

האייקונים אינם קבצים ידניים — הם נוצרים מהגדרה וקטורית אחת ב-`tools/make-icon.mjs`,
כך שכל הגדלים והוריאציות נשארים זהים זה לזה:

```bash
npm install
npm run icons
```

הפקודה כותבת את `icon.svg`, `icon-192/512.png`, את גרסאות ה-maskable,
`apple-touch-icon.png` ו-`favicon-32.png`.

## 🚀 פריסה

היישומון מתארח על Firebase Hosting (פרויקט `mil-time`):

```bash
firebase deploy --only hosting
```

הכתובת הזמנית היא https://mil-time.web.app — הדומיין `miltime.app` טרם נרכש.
לאחר רכישתו יש לעדכן את `<link rel="canonical">` ב-`index.html`.
